# 광곽에서 살아남기 (GSA LIFE)

광주과학고등학교 생활에서 착안한 비공식 브라우저 시뮬레이터입니다. 입학부터 졸업까지 6학기를 진행하며 공부, 운동부, 친구, 학생회, 수강신청과 진학을 경험합니다. 현재 버전은 **v0.13.1**입니다.

## 온라인 플레이와 배포

이 저장소의 `main` 브랜치에 변경이 올라가면 GitHub Actions가 `tests/`의 테스트를 모두 실행합니다. 모두 통과하면 `dist` 폴더가 GitHub Pages로 자동 배포됩니다. 진행 상황은 저장소의 **Actions** 탭에서 볼 수 있습니다.

## 실행하기

1. ZIP 파일을 모두 압축 해제합니다.
2. `dist` 폴더의 `index.html`을 Chrome 또는 Edge로 엽니다.
3. 이름과 캐릭터를 정해 입학합니다.

설치·빌드·API 키 없이 실행할 수 있습니다. 파일을 직접 여는 방식에서 저장이 제한된다면, Python이 설치된 컴퓨터에서 압축을 푼 폴더를 터미널로 열고 아래 명령을 실행하세요.

```sh
python -m http.server 8000 --directory dist
```

브라우저에서 `http://localhost:8000`을 열면 됩니다. 종료는 터미널에서 Ctrl+C를 누르세요.

## 저장 데이터

게임은 현재 브라우저에 자동 저장됩니다. 같은 주소와 같은 브라우저에서 다시 열면 이어 할 수 있습니다. 시크릿 모드·방문 기록 삭제·주소 변경에 따라 저장 데이터가 유지되지 않을 수 있습니다.

이 ZIP에는 프로그램과 그림이 들어 있습니다. 온라인 게임을 하던 브라우저의 개인 저장 데이터는 포함하지 않습니다. 온라인 주소와 파일 실행 주소의 저장 공간도 서로 다릅니다. 기존 온라인 저장 데이터는 같은 온라인 주소를 사용하면 이어집니다. v0.8에서는 이미 확정된 성적·수강 기록·관계를 보존하고 이후 시험에 조정된 난도를 적용합니다.

## 플레이 방법

- 매주 집중해서 키울 능력치를 고르고 한 주를 시뮬레이션합니다.
- 시험 2주 전 심야자습, 1주 전 새벽자습을 선택할 수 있습니다.
- 동아리·운동부·학생회 활동과 학교 행사가 사건으로 등장합니다.
- 친구·연애 화면에서 6명 중 더 알아가고 싶은 친구를 선택합니다. 친구별 만남과 친밀도는 각각 기록됩니다.
- 선택과목은 2학년 2학기부터 수강하며, 이수한 전문선택 과목에 따라 지원 가능한 전공이 달라집니다.
- 높은 점수를 받으려면 교과 준비, 자기관리, 피로와 스트레스를 함께 관리해야 합니다.
- 졸업과 대학 합격은 별도로 판정합니다. 게임 내 졸업 화면에서 TOEIC 730점, 현장연구 및 선택과목 이수 현황을 확인하세요.

## v0.13 변경 내용

- 연구활동(기초·심화자율연구, 졸업논문연구 등)은 이수/미이수로 평점에서 제외하고 이수 학점에만 넣습니다.
- 시험 난도: 반 평균이 수학·과학 약 70점, 인문 약 74~76점이 되도록 학기별 평균과 실력 차이 폭을 `EXAM_SHAPE`로 맞췄습니다. 봇 시뮬레이션(시험 전 심야자습을 적당히 쓰는 플레이) 기준 4.3 비율은 1학년 약 3%, 2학년 1학기 약 3%(중앙값 3.75), 이후 약 5~7%입니다.
- 심야·새벽자습 너프: 효과 하향, 연속 사용 시 효과 감소, 시험 날 피로 65 초과 시 감점.
- 학기 성적 발표와 성적표에 학년 동기 90명 기준 석차·누적 석차를 표시합니다(세이브 시드로 고정된 가상 동기).
- 교과우수상은 수강 인원의 5%를 소수 첫째 자리에서 올림한 인원에게 줍니다. 음악·미술·체육은 수행평가만으로 매기므로 능력치(체육은 운동, 음악·미술은 창의성)를 반영한 추첨으로 정합니다.
- **OVR과 잠재력**: 지능·연구·창의성·성실·리더십·사회성·회복력·운동 8개 능력치마다 시드로 정해진 숨은 잠재력(50~99)이 있고, 현재 값이 잠재력에 가까워질수록 성장이 줄어듭니다. 가중 평균으로 계산한 종합 능력치(OVR)를 프로필과 결과 카드에 표시합니다. 입학 OVR 중앙값은 약 49, 시뮬레이션 기준 졸업 OVR 90 이상 약 35%, 95 이상 약 15%, 99는 1% 미만입니다.
- **교내 대회**: 1학년 글쓰기·수학·물리·화학·생명과학 경시·동아리 발표, 2학년 영어 말하기·지구과학·정보과학 경시·R&E 발표, 학년마다 한 번씩 열리는 발명품 대회(전학년 참가)가 선택 사건으로 나옵니다. 지원자 수의 20%(올림)가 수상하며 상위부터 금·은·동상입니다. 준비 강도에 따라 수상 가능성과 피로가 달라집니다. 시뮬레이션 기준 보통 플레이의 수상률은 대회당 약 20~35%입니다(1학년 발명품 대회는 상급생과 겨뤄 더 어렵습니다).
- **입시 개편**: 지원 대학을 14곳(서울대, KAIST, POSTECH, GIST, DGIST, UNIST, 연세, 고려, 서강, 성균관, 한양, 중앙, 경희, 서울시립)으로 정리했습니다. 수시 원서는 6장(POSTECH 포함)까지, KAIST·GIST·DGIST·UNIST는 별도로 지원합니다. 면접은 서울대·KAIST·POSTECH·GIST·DGIST만 2문항씩 보고 나머지는 서류 평가입니다. 합격 확률은 원서 제출 시점의 학년 누적 석차 백분위를 중심으로 연구 역량, 교내 대회·교과우수·모범상·올림피아드 수상, 학생회·기장 경력, 면접, 전공 연계, 학과별 경쟁(컴퓨터·AI·전기전자 ↑, 지구과학 ↓)을 더한 로지스틱 모델입니다. 결과에는 서울대 학부·학과명이나 과기원 무학과 같은 모집단위 이름이 나옵니다. 시뮬레이션 기준 서울대 합격률은 약 47%(학년 90명 중 약 45명)입니다. 서울대 평점 4.0 초과 조건은 없앴고, 이전 버전에서 이미 지원한 다른 대학은 결과만 계산합니다.
- **주간 시간 배분**: 성장 방향 하나를 고르던 방식을 방과 후 시간 10칸 배분으로 바꿨습니다. 한 곳에 10칸을 몰면 예전 성장 방향과 같고, 나누면 각 활동 효과가 칸 수 비율만큼 섞입니다. 엔진 `simulateWeek`는 예전처럼 문자열 방향도 받습니다.
- **자습 플래너**: 시험 2주 전 주(2·6주차)에 사건으로 열리고, 시험 주까지 3주 × 월~금 달력에서 날짜별로 심야자습·새벽자습(시험 1주 전부터)을 정합니다. 한 주 효과는 켠 날 수 ÷ 5만큼 기존 심야·새벽자습 효과를 받습니다. 프리셋: 막판에(시험 전 주 심야) · 꾸준히(3주 심야) · 전력으로(심야 + 마지막 2주 새벽) · 직접.
- **TOEIC 선택 사건**: 1학년 2학기부터 준비도 5 이상이고 730점 미만이면 4주마다 「응시할래?」를 묻고, 응시를 고르면 다음 주에 시험을 봅니다(시험 직전 주 제외).
- **일상 사건 → 주간 보고서**: 일상 사건은 한 주에 1~3건이 대부분 자동으로 지나가고 보고서에 「이번 주 일상 사건 n건」과 목록으로 남습니다. 약 30%의 주에는 하나를 직접 고릅니다.
- **평가(A + B)**: A는 졸업 OVR과 업적 ★ 9종(최우수 졸업=누적 석차 3위 이내, 학생회장, 운동부 기장, 올림피아드 수상, 국가대표, 교내 대회 금상, 교과우수상 8개 이상, 서울대 합격, 졸업 OVR 95+)입니다. B는 졸업 뒤 커리어 에필로그로, 시드에 고정된 확률로 대학 → 박사 → 교수·연구원 → 젊은과학자상 → 학술동아리 분야의 최고상(물리·지구 노벨 물리학상, 화학 노벨 화학상, 생명 노벨 생리의학상, 수학 필즈상, 정보 튜링상)으로 이어집니다. 시뮬레이션 기준 박사 약 58%, 젊은과학자상 약 15%, 최고상 약 1%입니다. 회고 슬라이드·한 장 요약·결과 카드에 표시됩니다.
- 시작 화면에 패치노트를 표시합니다.
- 이미 확정된 성적은 그대로 두고, 진행 중인 학기는 기존 과목표로 끝낸 뒤 다음 학기부터 새 과목표를 적용합니다.

## v0.12 변경 내용

- **시작 화면**: 게임을 열면 큰 로고와 제목이 있는 시작 화면이 나옵니다. 이어하기(진행 중인 학생과 시점 표시), 새 게임, 튜토리얼, 기록실을 고를 수 있고, 오른쪽 위에 작은 도움말 버튼이 있습니다. 게임 중에는 왼쪽 위 로고나 「시작 화면」 버튼으로 돌아옵니다.
- **튜토리얼(선택)**: 「튜토리얼」을 고른 경우에만 실제 화면 위에서 입학 카드 → 첫 사건 → 성장 방향 → 일정 예약 → 자습 → 피로·스트레스 → 한 주 보내기 → 메뉴 → 도움말 순서로 안내합니다. 진행 중인 게임이 있으면 지우지 않고 지금 화면에서 안내합니다.
- **컴패리즌**: 이야기를 마치면 기록과 가장 닮은 과학자·수학자 25명 중 한 명(닮은 정도 %)과 다른 후보 2명, 졸업 후 연구자 유형을 알려 줍니다. 능력치와 함께 운동부·학생회·연구에 쓴 주, 수상, 만남, 회복 경험, 그리고 학술동아리·선택과목·지원 전공으로 본 분야를 비교합니다. 회고 마지막 장, 한 장 요약, 결과 카드 이미지에 담깁니다. 인물 소개는 노벨상·필즈상 발표와 대학·언론 보도 등 공개 자료를 바탕으로 요약했으며, 닮은 정도는 게임 속 재미 요소입니다.
- **기록실**: 마친 이야기(졸업·졸업 유예·중도 종료)를 최대 30개까지 한 줄 기록으로 보관하고, 만난 과학자를 과학자 도감으로 모읍니다.
- 처음 방문 안내와 업데이트 알림은 시작 화면이 맡습니다. 게임 규칙과 저장 데이터 구조는 바뀌지 않았습니다.

## v0.10 변경 내용

- 주간 용돈을 5,000원으로 조정했습니다. 초기 자금은 능력치를 보완하도록 지급하며 120개 시작 사례에서 15,000~22,000원이었습니다. 매점 소모품 가격과 도움 활동 보상도 조정했습니다.
- 균형 생활 중 4주에 한 번 공부에 집중하고 피로할 때 쉬는 루틴을 120번 검증한 결과, 졸업 평점 중앙값은 4.02/4.3이었습니다. 같은 루틴에 심야·새벽자습을 활용하면 약 4.13~4.14였습니다. 개인의 능력치와 사건에 따라 성적은 달라집니다.
- 심야자습과 새벽자습의 교과 이해 효과를 높였습니다. 추가 피로와 스트레스, 시작 가능한 시점은 유지합니다.
- 기존 대학에 연세대·고려대·성균관대·서강대·한양대·중앙대·경희대·서울시립대·한국외대·건국대·동국대·홍익대를 추가해 총 19곳을 지원할 수 있습니다. 원서는 1~3곳 제출합니다.
- 원서 제출 당시 누적 평점을 기준으로 대학마다 다른 합격 난도를 적용합니다. 서울대가 가장 어려우며 평점 4.0 초과가 필수입니다. 조건을 충족해도 면접과 전형 판정에 따라 불합격할 수 있습니다. 이는 실제 입시 기준이나 대학 순위가 아닌 게임 설정입니다.
- 대학 목록과 게임 난이도는 입학 직후부터 진학·졸업 화면에서 볼 수 있습니다.
- 기존 성적·중간고사·잔액·구매 내역·확정된 합격 결과는 보존합니다. 새로운 성적 산식은 앞으로 치를 시험에, 새로운 용돈은 이후 지급분에 적용합니다.

## v0.9 변경 내용

- 게임을 마치면 실제 기록을 바탕으로 입학, 학년별 순간, 활동, 친구, 마지막 진로를 차례로 돌아봅니다.
- 장면 또는 다음 버튼을 클릭하거나 좌우 방향키로 넘길 수 있습니다. 요약 바로 보기, 처음부터 다시 보기, 기록으로 돌아가기 기능을 제공합니다.
- 마지막에는 캐릭터, 평점, 수상, 학점, TOEIC, 현장연구, 관계, 동아리와 직책, 대학 전형 결과를 한 장의 카드로 모아 보여줍니다.
- 졸업 유예와 중도 종료도 실제 진행한 기간과 결과대로 표시합니다. 회고를 닫으면 남은 졸업 준비를 이어갈 수 있습니다.
- 나의 기록에서도 지금까지의 이야기를 볼 수 있습니다. 회고를 넘기는 행동은 시간·성적·관계·난수를 바꾸지 않습니다.
- 작은 캐릭터에 숨 쉬듯 움직이는 모션, 공부할 때 기울임, 운동할 때 점프, 졸업 장면의 축하 모션을 적용했습니다. 모션 끄기와 동작 줄이기 설정을 유지합니다.

## v0.8 변경 내용

- 큰 배경 일러스트를 작은 학생 캐릭터로 교체했습니다. 프로필·이벤트·친구 카드에 표시하며 모션을 끌 수 있습니다.
- 관심사가 다른 가상 친구 6명에게 별도의 만남, 대화, 관계와 쿨다운을 적용했습니다. 현재 교제 상대는 한 명입니다.
- 성적 산식에서 준비도와 높은 능력치의 누적 효과를 완만하게 하고, 과목 난도를 반영했습니다. A+ 90점과 5점 간격의 학점 기준은 유지했습니다.
- 2022·2024·2025년 학교 공식 교재 목록에서 확인한 과거 과목 14개를 추가했습니다. 여러 연도 과목을 함께 선택할 수 있도록 구성한 게임 목록이며, 실제 특정 학년도 수강 가능 목록을 뜻하지 않습니다.
- 기장 임기는 2학년 2학기 말에 끝납니다. 2학년 학생회 임원은 3학년 1학기 말까지 활동합니다. 종료된 활동 이력은 남습니다.

## 폴더 구성

- `dist/`: 실제 실행되는 HTML, CSS, JavaScript와 캐릭터 이미지
- `tests/`: 게임 규칙과 저장 데이터 호환성 검증 코드
- `archive/v0.7/`: 이전 큰 일러스트와 표시 모듈의 보관본. 현재 게임에서는 사용하지 않습니다.
- `dist/assets/characters/PROMPTS.md`: 캐릭터 이미지 제작 기록
- `dist/curriculum-guide.js`: 수강 안내와 공식 자료 링크
- `dist/extras-ui.js`, `dist/extras-ui.css`: 도움말, 처음 방문 안내, 저장 백업, 새 버전 안내
- `dist/share-card.js`: 결과 카드 이미지 그리기와 저장·공유
- `dist/version.json`: 배포된 버전 확인용 파일
- `dist/title-ui.js`, `dist/title-ui.css`: 시작 화면, 기록실(지난 이야기·과학자 도감)
- `dist/tutorial-ui.js`: 화면 위 단계별 튜토리얼
- `dist/scientists.js`: 컴패리즌 인물 데이터와 비교 계산

개발 검증에는 Node.js가 필요합니다. 프로젝트 폴더에서 다음 명령을 실행합니다.

```sh
node tests/engine.test.cjs
```

## 학교 자료와 게임 설정
