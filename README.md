# 광곽에서 살아남기 (GSA LIFE)

광주과학고등학교 생활에서 착안한 비공식 브라우저 시뮬레이터입니다. 입학부터 졸업까지 6학기를 진행하며 공부, 운동부, 친구, 학생회, 수강신청과 진학을 경험합니다. 현재 버전은 **v0.11**입니다.

## 온라인 플레이와 배포

이 저장소의 `main` 브랜치에 변경이 올라가면 GitHub Actions가 `tests/`의 테스트를 모두 실행합니다. 모두 통과하면 `dist` 폴더가 GitHub Pages로 자동 배포됩니다. 진행 상황은 저장소의 **Actions** 탭에서 볼 수 있습니다.

## 실행하기

1. ZIP 파일을 모두 압축 해제합니다.
2. `dist` 폴더의 `index.html`을 Chrome 또는 Edge로 엽니다.
3. 이름과 캐릭터를 정해 입학합니다.

설치·빌드·API 키 없이 실행할 수 있습니다. 파일을 직접 여는 방식에서 저장이 제한된다면, Python이 설치된 컴퓨터에서 압축을 푼 폴더를 터미널로 열고 아래 명령을 실행하세요.

```sh
python -m http.server 8000 --directory dist
```

브라우저에서 `http://localhost:8000`을 열면 됩니다. 종료는 터미널에서 Ctrl+C를 누르세요.

## 저장 데이터

게임은 현재 브라우저에 자동 저장됩니다. 같은 주소와 같은 브라우저에서 다시 열면 이어 할 수 있습니다. 시크릿 모드·방문 기록 삭제·주소 변경에 따라 저장 데이터가 유지되지 않을 수 있습니다.

이 ZIP에는 프로그램과 그림이 들어 있습니다. 온라인 게임을 하던 브라우저의 개인 저장 데이터는 포함하지 않습니다. 온라인 주소와 파일 실행 주소의 저장 공간도 서로 다릅니다. 기존 온라인 저장 데이터는 같은 온라인 주소를 사용하면 이어집니다. v0.8에서는 이미 확정된 성적·수강 기록·관계를 보존하고 이후 시험에 조정된 난도를 적용합니다.

## 플레이 방법

- 매주 집중해서 키울 능력치를 고르고 한 주를 시뮬레이션합니다.
- 시험 2주 전 심야자습, 1주 전 새벽자습을 선택할 수 있습니다.
- 동아리·운동부·학생회 활동과 학교 행사가 사건으로 등장합니다.
- 친구·연애 화면에서 6명 중 더 알아가고 싶은 친구를 선택합니다. 친구별 만남과 친밀도는 각각 기록됩니다.
- 선택과목은 2학년 2학기부터 수강하며, 이수한 전문선택 과목에 따라 지원 가능한 전공이 달라집니다.
- 높은 점수를 받으려면 교과 준비, 자기관리, 피로와 스트레스를 함께 관리해야 합니다.
- 졸업과 대학 합격은 별도로 판정합니다. 게임 내 졸업 화면에서 TOEIC 730점, 현장연구 및 선택과목 이수 현황을 확인하세요.

## v0.11 변경 내용

- 화면 위쪽 **도움말** 버튼과 바닥글 링크로 게임 가이드를 열 수 있습니다. 시작하기, 한 주 보내기, 시험·성적, 활동·친구, 수강·전공, 졸업·진학, 저장·백업, 자주 묻는 질문, 업데이트 소식으로 나뉩니다.
- 처음 방문하면 1분 안내가 열립니다. 기존 플레이어에게는 업데이트 알림이 한 번 표시됩니다.
- 진행 기록을 **백업 파일(.json)** 또는 **백업 코드**로 내보내고, 다른 브라우저·기기에서 불러올 수 있습니다. 불러오기 전의 기록은 `gsa-life-v1-before-import`에 한 번 더 보관합니다.
- 회고의 한 장 요약에서 **결과 카드 이미지**(1080×1350 PNG)를 저장하거나 휴대폰 공유 기능으로 보낼 수 있습니다. 평점, 수상, TOEIC, 이수 학점, 현장연구, 학기별 평점, 동아리·직책, 대학 전형 결과를 담습니다.
- 새 버전이 배포되면 새로고침 안내가 나타납니다. 버전은 `dist/version.json`과 `dist/extras-ui.js`의 `VERSION`, `index.html`의 `?v=` 값을 함께 올립니다.
- 링크 공유 시 미리보기 이미지(`og-image.png`)와 사이트 아이콘(`favicon.svg`)이 표시됩니다.
- 게임 규칙, 성적 산식, 저장 데이터 구조는 바뀌지 않았습니다.

## v0.10 변경 내용

- 주간 용돈을 5,000원으로 조정했습니다. 초기 자금은 능력치를 보완하도록 지급하며 120개 시작 사례에서 15,000~22,000원이었습니다. 매점 소모품 가격과 도움 활동 보상도 조정했습니다.
- 균형 생활 중 4주에 한 번 공부에 집중하고 피로할 때 쉬는 루틴을 120번 검증한 결과, 졸업 평점 중앙값은 4.02/4.3이었습니다. 같은 루틴에 심야·새벽자습을 활용하면 약 4.13~4.14였습니다. 개인의 능력치와 사건에 따라 성적은 달라집니다.
- 심야자습과 새벽자습의 교과 이해 효과를 높였습니다. 추가 피로와 스트레스, 시작 가능한 시점은 유지합니다.
- 기존 대학에 연세대·고려대·성균관대·서강대·한양대·중앙대·경희대·서울시립대·한국외대·건국대·동국대·홍익대를 추가해 총 19곳을 지원할 수 있습니다. 원서는 1~3곳 제출합니다.
- 원서 제출 당시 누적 평점을 기준으로 대학마다 다른 합격 난도를 적용합니다. 서울대가 가장 어려우며 평점 4.0 초과가 필수입니다. 조건을 충족해도 면접과 전형 판정에 따라 불합격할 수 있습니다. 이는 실제 입시 기준이나 대학 순위가 아닌 게임 설정입니다.
- 대학 목록과 게임 난이도는 입학 직후부터 진학·졸업 화면에서 볼 수 있습니다.
- 기존 성적·중간고사·잔액·구매 내역·확정된 합격 결과는 보존합니다. 새로운 성적 산식은 앞으로 치를 시험에, 새로운 용돈은 이후 지급분에 적용합니다.

## v0.9 변경 내용

- 게임을 마치면 실제 기록을 바탕으로 입학, 학년별 순간, 활동, 친구, 마지막 진로를 차례로 돌아봅니다.
- 장면 또는 다음 버튼을 클릭하거나 좌우 방향키로 넘길 수 있습니다. 요약 바로 보기, 처음부터 다시 보기, 기록으로 돌아가기 기능을 제공합니다.
- 마지막에는 캐릭터, 평점, 수상, 학점, TOEIC, 현장연구, 관계, 동아리와 직책, 대학 전형 결과를 한 장의 카드로 모아 보여줍니다.
- 졸업 유예와 중도 종료도 실제 진행한 기간과 결과대로 표시합니다. 회고를 닫으면 남은 졸업 준비를 이어갈 수 있습니다.
- 나의 기록에서도 지금까지의 이야기를 볼 수 있습니다. 회고를 넘기는 행동은 시간·성적·관계·난수를 바꾸지 않습니다.
- 작은 캐릭터에 숨 쉬듯 움직이는 모션, 공부할 때 기울임, 운동할 때 점프, 졸업 장면의 축하 모션을 적용했습니다. 모션 끄기와 동작 줄이기 설정을 유지합니다.

## v0.8 변경 내용

- 큰 배경 일러스트를 작은 학생 캐릭터로 교체했습니다. 프로필·이벤트·친구 카드에 표시하며 모션을 끌 수 있습니다.
- 관심사가 다른 가상 친구 6명에게 별도의 만남, 대화, 관계와 쿨다운을 적용했습니다. 현재 교제 상대는 한 명입니다.
- 성적 산식에서 준비도와 높은 능력치의 누적 효과를 완만하게 하고, 과목 난도를 반영했습니다. A+ 90점과 5점 간격의 학점 기준은 유지했습니다.
- 2022·2024·2025년 학교 공식 교재 목록에서 확인한 과거 과목 14개를 추가했습니다. 여러 연도 과목을 함께 선택할 수 있도록 구성한 게임 목록이며, 실제 특정 학년도 수강 가능 목록을 뜻하지 않습니다.
- 기장 임기는 2학년 2학기 말에 끝납니다. 2학년 학생회 임원은 3학년 1학기 말까지 활동합니다. 종료된 활동 이력은 남습니다.

## 폴더 구성

- `dist/`: 실제 실행되는 HTML, CSS, JavaScript와 캐릭터 이미지
- `tests/`: 게임 규칙과 저장 데이터 호환성 검증 코드
- `archive/v0.7/`: 이전 큰 일러스트와 표시 모듈의 보관본. 현재 게임에서는 사용하지 않습니다.
- `dist/assets/characters/PROMPTS.md`: 캐릭터 이미지 제작 기록
- `dist/curriculum-guide.js`: 수강 안내와 공식 자료 링크
- `dist/extras-ui.js`, `dist/extras-ui.css`: 도움말, 처음 방문 안내, 저장 백업, 새 버전 안내
- `dist/share-card.js`: 결과 카드 이미지 그리기와 저장·공유
- `dist/version.json`: 배포된 버전 확인용 파일

개발 검증에는 Node.js가 필요합니다. 프로젝트 폴더에서 다음 명령을 실행합니다.

```sh
node tests/engine.test.cjs
```

## 학교 자료와 게임 설정
